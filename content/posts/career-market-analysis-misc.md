# 진로 가치 우선순위 및 정보보호 직무 시장분석

## 1) 가치 우선순위 선정

### 중요한 가치 (상위 2개)

- 연봉
- 안정성

### 낮은 가치 (하위 2개)

- 자율성
- 조직문화

## 2) 시장 분석

### 희망 회사 (과제 기준 3개)

- 국정원
- KISA
- 토스

추가 분석 회사:

- SK Shieldus
- Theori

### 희망 직무

- 정보보호(Security Researcher)

## 3) 공고/채용 정보 조사 요약 (총 5개)
![step1](/images/NIS3.png)
### 1. 국정원 - 정보보호
![step1](/images/NIS1.png)
- 분야: 정보(수집/활동/분석), 과학기술(SW/통신/정보보호/AI), 어학
- 선발 과정:
  서류 심사 -> 필기 시험(국가정보적격성검사, 전공 논술) -> 체력검정 -> 신체검사/면접 + 코딩 테스트
- 공채 시기: 상반기, 하반기
- 가산점 요소: TOEIC/TOEFL, 한국사, 무술(3단 이상), ICT, 영어 말하기
- 인재상: 애국심, 책임감, 전문지식, 정보감각, 보안의식
![step1](/images/NIS2.png)
- 필요 역량: 기술적 전문 지식, 분석/대응 능력, 책임감
- 공고 링크:https://career.nis.go.kr

![step1](/images/KISA5.png)
### 2. KISA - 정보보호 진단/분석
- 분야:
  정보보호 관리/운영, 차세대 기술연구, 정보보호 진단/분석, 개인정보보호, 보안사고 분석, IT 시스템 운영/관리
- 선발 과정:
  지원서 -> 서류 -> 필기(인성/조직적합도, NCS, 직무수행능력) -> 1차 면접(직무역량) -> 2차 면접(인성/조직적합성)
  ![step1](/images/KISA4.png)
- 공채 시기:
  ![step1](/images/KISA2.png)
- 담당 업무:
  국가 주요 정보통신기반시설의 사전 예방 중심 기술적/관리적 지원
- 인재상
![step1](/images/KISA3.png)
- 필요 역량: 기술적 전문지식, 정책/제도 이해, 소통/성장성, 책임감
- 공고 링크: https://kisa.applyin.co.kr/

### 3. 토스 - Security Researcher
![step1](/images/TOSS1.png)
- 선발 과정:
  지원서 제출 -> (필요 시) 전화 인터뷰/사전과제 -> 직무 인터뷰 -> 컬처핏 인터뷰 -> 레퍼런스 체크/처우 협의
- 담당 업무:
  웹/모바일 모의해킹 및 취약점 점검, APT 모의해킹, 공격/방어 기법 연구, 서비스 구조 보안 설계
![step1](/images/TOSS2.png)
- 인재상:
  공격자 관점 사고, 성장 가능성, 넓고 깊은 보안 이해, 문제 개선 능력
- 필요 역량: 기술적 전문지식, 경험 설명/정리 능력, 문제 판단/해결 능력
- 공고 링크: https://toss.im/career/jobs

### 4. SK Shieldus - 취약점 진단
![step1](/images/SK.png)
- 선발 과정: 서류전형 -> SKST(인성검사) -> 실무면접 -> 합격자 발표
- 담당 업무: 모의해킹, 인프라 진단, 진단 보고서 작성
- 인재상:
  IT 기본 이해를 바탕으로 정확한 취약점 식별과 끈기 있는 분석이 가능한 인재
- 필요 역량: 기술적 전문지식, 끈기/열정, 분석 결과 문서화/보고서 역량
- 공고 링크 :https://www.skshieldusapply.com/ko/o/209717

### 5. Theori - Offensive Security Researcher
![step1](/images/TORI.png)
- 선발 과정:
  서류전형 -> 스킬 테스트 -> 직무 인터뷰 -> 컬처 인터뷰 -> 레퍼런스 체크 -> 처우 협의
- 담당 업무:
  소스코드 오디팅/아키텍처 리뷰, 블랙박스 진단, APT 모의침투, 리버싱/익스플로잇, 인프라/클라우드 보안 진단, 1-Day 분석 및 PoC/Exploit 작성
- 인재상:
  공격자 관점 기반의 깊은 이해, 팀워크, 도전/성장 의지, 책임감/윤리의식
- 필요 역량: 기술적 전문지식, 넓은 사고력, 책임감/윤리의식
- 공고 링크: https://careers.theori.io/ko/jobs

## 4) 공고 5개에서 반복된 핵심 역량 3개

- 기술적 전문지식
- 분석 및 문제 해결 능력
- 책임감(윤리의식 포함)

## 5) 지금 내가 해야 할 것 1가지

`실전형 진단 보고서 1개를 완성해 공개 가능한 포트폴리오로 정리하기`

- 이유:
  대부분의 공고에서 기술력 자체뿐 아니라 분석 결과를 논리적으로 설명하고 문서화하는 능력을 공통적으로 요구
- 실행 방식:
  웹 취약점 1건을 선정해 재현 -> 원인 분석 -> 영향도 평가 -> 대응 방안 -> 최종 보고서 형태로 작성 후 블로그 게시.
