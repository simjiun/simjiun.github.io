# Blog routing with Next.js

The old version of this blog used manually written `index.html` files for every route.

Now the route is generated by the Next.js app router, and the post body is loaded from a Markdown file.

## Why this is better

- Writing a new post only needs one `.md` file.
- The route `/posts/slug` is generated automatically.
- Category pages can reuse the same metadata.

## New posting flow

1. Add a file under `content/posts`.
2. Fill the frontmatter.
3. Push the repository.

```md
---
title: "new post"
date: "2026-04-07"
category: "ctf"
section: "security"
---
```
